# Privacy Policy

AI Career Coach is a Claude Code plugin that runs entirely on your local machine.

- **No data is collected.** The plugin does not send any data to external servers, APIs, or third parties.
- **No analytics or telemetry.** There is no tracking of any kind.
- **All data stays local.** Your career encyclopedia, JD analyses, tailored CVs, and all other files are stored in your local workspace folder. Nothing leaves your machine beyond what Claude Code itself does.
- **No accounts required.** The plugin has no registration, login, or user accounts.

The plugin is open-source under the MIT License. You can inspect the full source code at [github.com/max-favilli/ai-career-coach](https://github.com/max-favilli/ai-career-coach).
